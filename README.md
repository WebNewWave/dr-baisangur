# Концепт 1 — Editorial SPA

Перенос эстетики журнала Dr.Bitiev в интерактивный веб. Серо-голубая палитра, крупный Cormorant Garamond, минималистичные линии, много воздуха.

## Особенности
- **Single Page Application** на чистом JS — навигация между экранами без перезагрузки (History API)
- **Плавные fade-переходы** между экранами (300ms ease-out, по правилам `review-animations`)
- **Cormorant Garamond** (display) + **Inter** (UI)
- **prefers-reduced-motion** уважается
- **Mobile-first** адаптивность
- **Без зависимостей** — чистый HTML/CSS/JS, готов к GitHub Pages

## Структура
```
concept-1-editorial/
├── index.html          # SPA-оболочка со всеми 9 экранами
├── css/style.css       # Дизайн-токены + секции + переходы
├── js/main.js          # SPA-роутер, прогресс, mobile nav
└── assets/             # Фото врача, кейсы, отбеливание, логотип
```

## Экраны (по hash-маршрутам)
- `#/` — Hero
- `#/about` — О враче (биография)
- `#/services` — Специализация (6 услуг)
- `#/technologies` — Технологии (6 направлений)
- `#/advantages` — Преимущества
- `#/cases` — Кейсы пациентов (3 истории с фото до/после)
- `#/myths` — Мифы или правда
- `#/recommendations` — Рекомендации
- `#/contact` — Контакты + Telegram CTA

## Палитра
| Токен | Значение | Применение |
|---|---|---|
| `--c-bg` | `#F5F2EC` | Основной фон |
| `--c-blue` | `#A8B5C2` | Фирменный серо-голубой из журнала |
| `--c-ink` | `#0E0E0E` | Чёрный для текста и CTA |
| `--c-text` | `#3A3F47` | Основной текст |
| `--c-blue-deep` | `#7E8FA0` | Hover-вариант синего |

## Известные риски (для production)
- Использованы реальные фото пациентов из журнала — для публичного сайта нужно письменное согласие пациентов (152-ФЗ).
- Шрифты загружаются с Google Fonts — если нужна полная приватность, можно перевести на self-hosted.
